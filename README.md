# Memory Match PWA

A plain HTML, CSS and JavaScript memory game configured as an installable Android PWA.

## Run on Chrome
1. Open the URL https://southpawprash.github.io/memory-match in Chrome.
2. Use the Install button if Chrome offers it, or Chrome menu → Install app / Add to Home screen.

## Files
- `index.html` — game, styling and JavaScript
- `manifest.json` — install metadata and landscape preference
- `service-worker.js` — offline app-shell caching
- `icon-192.png`, `icon-512.png` — app icons
